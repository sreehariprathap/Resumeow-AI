# Templates

Save your resume and cover letter setups so you can reuse them.

## What you can save

- Resume templates (layout and base content).
- Cover letter templates.
- Custom AI prompts.

## How to use

1. Build a resume or cover letter you like.
2. Save it as a template and give it a name.
3. Next time, pick it from the template list to start fast.

## Tips

- Templates sync to your account, so they show up on any device.
- Keep one template per job type (e.g. "Frontend", "Data") for quick switching.
