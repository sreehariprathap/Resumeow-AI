# ATS Analysis & Cover Letter

Two tools that help your application get past filters and read well.

## ATS Analysis

ATS (Applicant Tracking System) is the software companies use to filter resumes.

What it checks:
- Keyword match with the job.
- Skills alignment.
- Experience match.
- ATS-friendly formatting.

How to use:
1. Load your resume and paste the job description.
2. Run the analysis.
3. Read the score and the list of missing keywords.
4. Apply the suggested fixes.

## Cover Letter Generator

Writes a cover letter that matches the job.

How to use:
1. Make sure your resume and the job description are loaded.
2. Open the cover letter tool.
3. Add any optional instructions (tone, points to stress).
4. Generate, then review and copy.

## Tips

- Keep keywords honest — only include what is true for you.
- You can save good cover letters as [templates](./templates.md).
