# JD Matcher

Compares your resume to a job description and shows how well they fit.

## What you get

- A match score.
- Keywords you already have (matched).
- Keywords you are missing.
- A cover letter opening line you can reuse.

## Steps

1. Open **JD Matcher**.
2. Paste the job description.
3. Make sure your resume is loaded.
4. Run the match.
5. Read the score and the matched vs. missing keywords.

## Tips

- Add the missing keywords to your resume only if they are true for you.
- A higher match score usually means a better chance with ATS filters.
