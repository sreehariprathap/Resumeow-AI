# Scan a Job Page

The extension reads the job page so it knows what you are applying to.

## What it picks up

- Job title.
- Company name.
- Job description.

## How it works

1. Visit a job page on a supported site.
2. The extension scans the page automatically.
3. Click the icon to see the job it found (title and company).

## If it does not detect a job

- You will see a "not on a job page" message with the list of supported sites.
- Make sure you are on the actual job posting, not a search list.

See [supported-sites.md](./supported-sites.md) for where it works.
