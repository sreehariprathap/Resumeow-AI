# Auto-Fill the Form

The main job: fill the application form for you.

## Steps

1. Detect the job and pick a resume.
2. Start the auto-fill.
3. The extension uses AI to match your details to the form fields.
4. Watch the fill status.

## After it runs

- You see which fields were filled.
- You see any fields it skipped (it could not match them).
- Review the form, fix anything skipped, then submit yourself.

## Tips

- Always check the form before you submit.
- Skipped fields are usually unusual questions — fill those by hand.
