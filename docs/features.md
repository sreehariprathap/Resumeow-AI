# Resumeow-AI Features

| Feature | Description |
|---|---|
| AI Resume Generation | Automatically generates ATS-friendly resumes using Gemini/DeepSeek |
| Onboarding Wizard | Collects user information step-by-step and maps it to a resume profile |
| Resume Iteration | Users can automatically preview their generated resume and iterate on it via AI chat in a split-screen editor on the Resume page. |
| Profile Data Export/Import | Users can export their full profile data to JSON and import it back |
| Resume Library & Management | Grid view of all saved resumes with preview, edit, duplicate, and delete capabilities |
| Admin LLM Health Check | Interactive modal for admins to test all configured AI tasks across free and pro tiers in real-time |
| Profile Enhancements | Card-based UI for viewing profile data, AI-generated profile summary, and PDF download of the profile via LaTeX |
| Admin Token Requests | Test token request workflow in Admin Dashboard |
| Auto Cover Letters | Automatically generate a LaTeX cover letter matching the resume template style upon onboarding |
| Select-to-Score | Resume Scoring page now lists your generated resumes and allows direct selection for ATS analysis |
