# Resumeow Docs

Resumeow helps you tailor your resume to a job and apply faster, using AI.

It comes in three forms. Pick the one you use and open its folder.

| App | Folder | Best for |
|-----|--------|----------|
| 🌐 Web | [web/](./web/overview.md) | Building, scoring, and tailoring resumes on a big screen |
| 📱 Mobile | [mobile/](./mobile/overview.md) | Quick checks and tracking jobs on the go |
| 🧩 Extension | [extension/](./extension/overview.md) | Auto-filling job applications while you browse |

Each folder has:
- `overview.md` — what the app does and how to start.
- One file per feature — short, step-by-step.

You sign in with the same account everywhere, so your data follows you.
