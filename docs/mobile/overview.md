# Mobile App — Overview

The mobile app is the on-the-go version of Resumeow. Built with Expo (works on iOS and Android).

## What it does

- Upload a resume and run AI checks from your phone.
- Get a resume analysis, ATS score, and cover letter.
- Track the jobs you applied to.
- See your token balance and plan.

## How to start

1. Open the app.
2. Sign in, or register if you are new.
3. First time only: swipe through the short onboarding.
4. Land on the Home tab and start.

## Tabs

The app has four tabs at the bottom:

| Tab | What it is |
|-----|------------|
| Home | Run AI tools on your resume → [home-ai-tools.md](./home-ai-tools.md) |
| Analyze | View results: analysis, cover letter, ATS → [analyze.md](./analyze.md) |
| Tracker | Track job applications → [tracker.md](./tracker.md) |
| Profile | Account, plan, tokens → [profile-tokens.md](./profile-tokens.md) |

## Other features

- [sign-in.md](./sign-in.md) — sign in and register
- [onboarding.md](./onboarding.md) — first-run intro

## Good to know

- You use the same account as the web app, so your data matches.
- AI actions use tokens. Your balance shows in a badge at the top.
