# Onboarding

A short intro you see the first time you open the app.

## What it does

- Swipes through a few slides that explain what Resumeow does.
- Sets you up so the app is ready to use.

## Steps

1. Read each slide and swipe to the next.
2. Tap the button on the last slide to finish.
3. You land on the Home tab.

## Note

You only see this once. After that, the app opens straight to Home.
