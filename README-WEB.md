# Web version of Prompter

This project has been converted from a Chrome extension to a full-featured web application.

## Features

- Create optimized resume prompts for AI assistants
- Generate customized cover letter prompts
- Save and manage multiple templates
- Secure authentication with Firebase
- Responsive design for all screen sizes

## Development

### Setup

1. Clone the repository
2. Create a `.env` file with your Firebase credentials based on `.env.example`
3. Install dependencies:

```
npm install
```

4. Start the development server:

```
npm run dev
```

## Building for Production

To build the app for production:

```
npm run build
```

The build output will be in the `build` directory.

## Deployment

Deploy the app using your preferred hosting service:

- Firebase Hosting
- Vercel
- Netlify
- GitHub Pages
