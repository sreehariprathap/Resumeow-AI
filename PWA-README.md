# Prompter PWA Guide

This document explains how to build and deploy Prompter as a Progressive Web Application (PWA).

## Features

The PWA version of Prompter includes:

- ✅ **Offline Support**: Core functionality works without internet
- ✅ **Installable**: Can be installed on devices like a native app
- ✅ **Auto-Updates**: Automatically updates when new versions are available
- ✅ **Push Notifications**: (Ready for future implementation)
- ✅ **Responsive Design**: Works on all screen sizes
- ✅ **Fast Loading**: Cached resources for quick startup
- ✅ **App Shortcuts**: Quick access to common actions

## Building for PWA

### Development
```bash
# Start PWA development server
npm run dev:pwa

# Preview PWA build
npm run preview:pwa
```

### Production Build
```bash
# Build PWA version
npm run build:pwa
```

This will create a `build/` directory with:
- Optimized PWA manifest
- Auto-generated service worker
- Cached assets for offline use
- All necessary PWA files

## Deployment Options

### 1. Static Hosting (Recommended)

Deploy the `build/` folder to any static hosting service:

- **Netlify**: Drag and drop the build folder
- **Vercel**: Connect your GitHub repo and set build command to `npm run build:pwa`
- **GitHub Pages**: Deploy from the build folder
- **Firebase Hosting**: Use `firebase deploy` after build
- **Cloudflare Pages**: Connect repo with build command `npm run build:pwa`

### 2. Manual Deployment

1. Build the PWA: `npm run build:pwa`
2. Upload the entire `build/` folder to your web server
3. Ensure your server supports HTTPS (required for PWA features)
4. Configure your server to serve the app with proper headers

## PWA Installation

### For Users

1. **Mobile (Chrome/Safari)**:
   - Visit the PWA URL in browser
   - Tap the "Add to Home Screen" prompt
   - Or use browser menu > "Add to Home Screen"

2. **Desktop (Chrome/Edge)**:
   - Visit the PWA URL
   - Click the install icon in the address bar
   - Or use the install banner that appears

3. **Manual Install**:
   - Chrome: Menu > "Install [App Name]"
   - Edge: Menu > "Install this site as an app"

### Installation Features

- **Desktop**: Creates an app icon in applications menu
- **Mobile**: Adds icon to home screen
- **Standalone Mode**: Runs without browser UI
- **Auto-Launch**: Can be set as default for certain file types

## PWA vs Extension

| Feature | PWA | Extension |
|---------|-----|-----------|
| Installation | Via browser | Via Chrome Web Store |
| Platform | All modern browsers | Chrome-based browsers |
| Offline Support | ✅ Full | ✅ Limited |
| Auto Updates | ✅ Automatic | ✅ Store-managed |
| Native Integration | Limited | Full browser integration |
| Distribution | Direct URL | Store approval required |

## Troubleshooting

### Common Issues

1. **PWA not installable**:
   - Ensure HTTPS is enabled
   - Check manifest.json is valid
   - Verify service worker registration

2. **Offline features not working**:
   - Check service worker is registered
   - Verify caching strategy
   - Test network connectivity

3. **Install prompt not showing**:
   - Ensure all PWA criteria are met
   - Check browser support
   - Verify manifest configuration
